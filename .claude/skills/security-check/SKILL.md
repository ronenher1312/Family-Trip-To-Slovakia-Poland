# כללי אבטחה לפני התקנת קבצים חיצוניים

## מתי להפעיל
לפני **כל** התקנה של:
- סקילים חיצוניים
- סקריפטים
- תלויות (dependencies)
- קבצי config
- כל קוד שמגיע ממקור חיצוני

## תהליך הבדיקה — חובה לבצע לפני התקנה

1. **קרא את כל הקבצים** שורה אחר שורה לפני כל פעולה
2. **בדוק את רשימת הסכנות הבאה**
3. **אם נמצא חשש כלשהו** — עצור, התרע, אל תתקין

## רשימת בדיקות חובה

### רשת ותקשורת
- [ ] האם הקוד פותח חיבורי רשת לכתובות לא ידועות?
- [ ] האם יש הורדה אוטומטית של קבצים נוספים?
- [ ] האם יש שליחת מידע החוצה (credentials, קבצים, env vars)?

### הרצת קוד
- [ ] האם יש `subprocess` / `exec` / `eval` עם קלט לא מסונן?
- [ ] האם יש `LD_PRELOAD` או שינוי של משתני סביבה חשובים?
- [ ] האם יש קוד מקמפל (gcc, cc) שמריץ קוד דינמי?

### גישה לקבצים
- [ ] האם הקוד ניגש לקבצים מחוץ לתיקיית הפרויקט?
- [ ] האם יש גישה ל-`~/.ssh`, `~/.aws`, `.env`, או קבצי סיסמאות?
- [ ] האם הקוד כותב לתיקיות מערכת (`/etc`, `/usr`, `/bin`)?

### ערפול וסתירה
- [ ] האם יש קוד מוצפן או מעורפל (base64, hex strings, obfuscation)?
- [ ] האם שם הקובץ/פונקציה לא מתאים למה שהקוד עושה?
- [ ] האם יש URLs קשיחים בתוך הקוד לשרתים לא מוכרים?

### מקור הקוד
- [ ] האם הקוד מגיע מריפו רשמי ומוכר?
- [ ] האם הריפו עם כוכבים, תיעוד, ופעילות אמיתית?
- [ ] האם הקוד עבר עדכונים חשודים לאחרונה?

## כלל הזהב

> אם יש **חשש כלשהו, ולו הקטן ביותר** — עצור והתרע למשתמש לפני כל פעולה.

## פורמט התרעה חובה

אם נמצאת בעיה, דווח כך לפני כל פעולה אחרת:

```
⚠️ התרעת אבטחה — לא מתקין

קובץ: <שם הקובץ>
בעיה: <תיאור מדויק של מה שמחשיד>
שורה: <מספר שורה אם רלוונטי>
המלצה: <אל תתקין / בדוק עם מומחה / ניתן להתקין אחרי שינוי X>
```

## אחרי בדיקה נקייה

רק אם עברו **כל** הבדיקות ללא חשש — דווח:

```
✅ בדיקת אבטחה עברה — בטוח להתקין
בדקתי: <רשימת הקבצים שנבדקו>
ממצאים: לא נמצאו בעיות
```
